# Third-Party Notices

The benchmark release contains scoped snapshots and runtime material from
third-party open-source projects. Those materials are not relicensed by this
repository. Their original license and notice files are preserved within the
corresponding case assets.

`release/benchmark_manifest.json` records the advisory, upstream repository,
source commit, and component identity for every case. Consumers are responsible
for complying with the licenses that apply to each upstream asset.

Container images are referenced by immutable image ID and are not included in
the benchmark source repository or benchmark release archive. Distribution of
container images requires a separate license and provenance review.
